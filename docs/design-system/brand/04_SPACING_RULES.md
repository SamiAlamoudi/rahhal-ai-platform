# Spacing Rules

## Base unit

**4px** grid. Prefer multiples of 8 for section rhythm.

| Token | Value | Use |
|-------|-------|-----|
| space-1 | 4 | Icon gaps |
| space-2 | 8 | Inline clusters |
| space-3 | 12 | Chip padding |
| space-4 | 16 | Card padding (compact) |
| space-5 | 24 | Card padding (default) |
| space-6 | 32 | Section gaps |
| space-7 | 48 | Major section breaks |
| space-8 | 64 | Hero breathing room |

## Composition

- First viewport: brand + one headline + one sentence + one CTA group + one dominant visual (Orb / horizon). No stat strips.
- Cards only when they hold interaction.
- Floating layers: 16–24px inset from viewport edges on mobile; 32px on desktop.

## Optical

Arabic labels may need +2–4px vertical padding vs Latin equivalents. Keep optical centers aligned for Orb + label pairs.
