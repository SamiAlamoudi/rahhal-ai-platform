# Future Expansion Rules

## How to grow without dilution

1. **Extend tokens first** — new hues/patterns must map to horizon / tide / dune / mist / ember.
2. **Orb is sacred** — do not replace with a mic, avatar photo, or lettermark in AI contexts.
3. **Travel DNA before new icons** — add a category mark before inventing a one-off SVG.
4. **Gallery gate** — every new brand surface ships with a Brand-tab specimen on `/design-system`.
5. **Docs with code** — update this brand book in the same PR as visual changes.

## Allowed expansions

- Seasonal horizon washes (still tide/dune family)
- Partner co-brand *secondary* marks (never replace Orb)
- Lottie/Rive ports of existing CSS Orb states (same timing)

## Forbidden expansions

- Dark-mode neon cyber theme as default brand
- Mascot characters
- Per-feature color systems that ignore Travel DNA
- Sound without mute + reduced-motion pairing

## Versioning

Brand Experience versions: Foundation → Premium V2 → **Signature (this)**. Next visual major bump only when DNA principles change — not for routine component polish.
