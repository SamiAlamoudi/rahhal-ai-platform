# AI Personality Visuals

Every AI state has a visual identity via `AiPersonality` chips + Orb pairing.

| State | Arabic cue | Visual |
|-------|------------|--------|
| Thinking | يفكّر | Orbit shimmer, Orb thinking |
| Reasoning | يستنتج | Dual-tick pulse |
| Memory | يتذكّر | Soft gold underline mist |
| Recommendations | يقترح | Dune edge card glow |
| Searching | يبحث | Compass tick sweep |
| Comparing | يقارن | Split mist bars |
| Booking | يحجز | Tide progress fill |
| Confirmation | يؤكّد | Success pulse + check |

## Rules

- Always pair copy with a state chip — never orphan status text.
- Streaming replies use mist stream under the message, not a typing “...” bounce.
- Errors use ember chip + Orb error; apology copy stays calm.
