# Illustration Rules

## Style

**Minimal. Elegant. Luxury. International.**

- Geometric horizon lines, dune arcs, compass ticks, soft mist ellipses
- Flat + subtle gradient fills only (no skeuomorphism)
- Stroke 1.5–2px optical; round joins
- No cartoons, mascots with faces (the Orb is the face of AI), no stock suitcase tropes as hero art

## Palette inside illustrations

Tide, mist, dune gold, deep ink. Max **three** hues per illustration. White is structure, not fill spam.

## Formats

- Inline SVG React components in `Illustrations.tsx`
- ViewBox 120×80 or 160×100 for wide marks; 64×64 for square companions
- Decorative: `aria-hidden`; meaningful: provide Arabic `title`

## Allowed motifs

Horizon, dune, companion path, atlas grid, tide ring, journey arc, mist veil.

## Forbidden motifs

Planes with cartoon smiles, passport stamps as clutter, palm-tree clipart, globe with generic pins as default hero.
