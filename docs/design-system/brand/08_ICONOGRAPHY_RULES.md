# Iconography Rules

## Optical sizing

| Box | Live stroke | Use |
|-----|-------------|-----|
| 16 | 1.5 | Dense UI |
| 20 | 1.75 | Default |
| 24 | 2 | Toolbar / Travel DNA |
| 32 | 2 | Featured |

Icons sit in a **24×24** keyline with 2px padding; optical center, not geometric, for asymmetric marks (flight, map pin).

## Stroke

- Round caps and joins
- Consistent corner radius ≈ 1.5–2px
- No filled+outline mix inside one glyph unless Travel DNA requires a solid core

## Spacing

- Icon-to-label gap: 8px
- Icon-only hit target: ≥44px
- Align baselines of Arabic labels to icon optical mid

## Travel DNA

Category marks share the same viewBox, stroke, and tide/gold dual-tone rule. See [12_TRAVEL_DNA.md](./12_TRAVEL_DNA.md).

## Forbidden

- Emoji as icons
- Multi-color flat icons from mixed packs
- 3D / skeuomorphic glyphs
