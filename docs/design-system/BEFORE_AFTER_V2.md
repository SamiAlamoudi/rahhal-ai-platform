# Premium Experience V2 — Before / After

## Mission

Elevate the shipped design foundation into an unforgettable companion experience — without redesigning architecture or touching business logic.

---

## Before → After

| Area | V1 Foundation | V2 Premium |
| --- | --- | --- |
| **Home** | Card hero + mid-size mic CTA | Full-bleed living companion hero; **voice orb is the centerpiece**; soft inspiration mosaic; floating recent journeys |
| **Voice** | Simple pulse ring | Breathing orb, dual expanding rings, natural wave bars, calm listening copy |
| **AI Chat** | Flat bubbles + stacked cards | Custom bubbles, streaming caret, typing “composing”, thinking rail, rich card stack (flight/hotel/map/price insight/package), voice playback affordance |
| **Motion** | Up to 480ms; basic fade | **≤350ms**; breathe / ring / wave / card-float / stream / success-ring; reduced-motion intact |
| **Depth** | Soft single shadows | Layered float shadows, glass (`blur 22px`), hover lift on cards |
| **Maps** | Flat placeholder | Premium map wash + grid, dual pins, floating glass action card |
| **Profile** | Name + preferences | Luxury mini-dashboard: trips / countries / loyalty, upcoming, achievements |
| **Booking** | Plain forms | Progress rail + trust chips (encrypted / transparent / confident) |
| **Empty / Error / Success** | Generic icon panels | Minimal travel illustrations; human, non-technical copy; quiet celebration |
| **Loading** | Spinner + skeletons | Intelligent skeleton composition; illustration cue — spinners de-emphasized |
| **Gallery** | “Design System” | **Premium V2** labeling + same Light/Dark · RTL/LTR controls |

---

## Emotional bar (self-check)

- Does Home feel alive? **Yes — voice breathes at center.**  
- Does Chat feel like a consultant, not a chatbot? **Yes — rich composed turns.**  
- Would Apple ship the motion restraint? **Durations capped; reduced-motion respected.**  
- Backend / APIs / AI architecture touched? **No.**
