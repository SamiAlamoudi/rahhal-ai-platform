# Visual Identity — Signature Brand

Rahhal must be recognizable from a single screenshot: ocean-horizon light, dune-gold accents, signature glass, and the **Rahhal Orb** as the face of AI.

## Brand feeling

Calm ocean intelligence. Modern Arabic elegance. Luxury travel without cliché. A private consultant — not an OTA marketplace.

## Color story

| Role | Expression |
| --- | --- |
| Deep Ocean / Tide | Trust, depth, primary actions |
| Elegant Turquoise | Coastline life, AI calm |
| Dune gold | Warm luxury accent, success |
| Pearl / Warm White | Quiet canvas, glass fills |
| Ember | Rare error / urgency |

See the full brand book: [`brand/README.md`](./brand/README.md).

## Signature system

- Gradients: horizon · dusk · pearl · AI glow · insight
- Glass: pearl translucency + blur + mist border
- Shadows: cool tide-ink lift / float / orb stage
- Patterns: dune bands · compass ticks · mist mesh (≤8% contrast)
- Separators: horizon hairline fades

## Composition rules

- One job per section
- Brand is hero-level on entry surfaces
- Voice / Orb is the primary AI mark
- Cards exist for interaction, not decoration
- Prefer atmosphere washes over loud gradients
- No purple-AI kitsch, cream-terracotta templates, or cartoon mascots

## Typography

- Display / UI Latin: Plus Jakarta Sans
- Arabic body & bilingual UI: Cairo (Tajawal fallback)
- Large heroes, comfortable callouts, never dense marketplace type

## Motion

Calm and expensive. UI transitions ≤350ms. Orb state motion is proprietary; respect `prefers-reduced-motion`.
