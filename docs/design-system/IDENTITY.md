# Visual Identity

## Brand feeling

Calm ocean intelligence. A private travel consultant in your pocket.

## Color story

| Role | Expression |
| --- | --- |
| Deep Ocean Blue | Trust, depth, navigation |
| Elegant Turquoise | Life, coastline, secondary accent |
| Warm White | Quiet paper, restful canvas |
| Pure White | Surfaces that float softly |
| Premium Green / Amber / Red | Success / caution / error — never neon |

## Composition rules

- One job per section  
- Brand is hero-level on entry surfaces  
- Voice is the primary CTA on Home  
- Cards exist for interaction, not decoration  
- Prefer atmosphere washes over loud gradients  
- Glass only on floating nav / composers  

## Typography

- Display / UI Latin: Plus Jakarta Sans  
- Arabic body & bilingual UI: Cairo (Tajawal fallback)  
- Large heroes, comfortable callouts, never dense marketplace type
